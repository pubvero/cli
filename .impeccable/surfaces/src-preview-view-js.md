# Local connected preview

Operate surface for authors editing an existing Pubvero Page. The user confirmed the narrow layout: full-window Page, compact connection/version bar, reload; publication remains in the terminal. Inherits the existing Pubvero viewer world, not a new identity.

## Direction contract

THESIS: inspect the actual authored Page with authorized data; the platform frame remains secondary, without a dashboard or card container.

OWN-WORLD: inherited warm paper/carbon palette and forest action green; Avenir/system operational text, fine separator, 44px reload target, visible focus. Follow system light/dark preference because authors work alongside their editor under varying ambient light.

STORY: see the connected instance and pinned version, inspect the Page, edit the local file, reload. Errors replace the preview with an explicit recovery message; never imply stale content is current.

FIRST VIEWPORT: compact wrapping top bar with Pubvero, Page title, instance/version status and reload action; iframe consumes all remaining width and height. Small screens wrap the bar, not the Page into a miniature rectangle.

FORM: exact user-approved narrow extension of the hosted viewer; no concept seed required. Signature interaction is reload with a disabled, labeled pending state and announced completion/error. No decorative motion; reduced-motion remains settled.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
